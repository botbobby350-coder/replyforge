# ReplyForge ⚡

**AI-powered cold email personalizer. Paste a URL, get a personalized email in seconds.**

## What it does

1. User pastes a LinkedIn profile or company URL
2. AI scrapes key context and crafts a personalized cold email
3. User copies, sends, closes deals

## Stack

- **Frontend:** Next.js 14 + Tailwind CSS
- **Backend:** Next.js API routes
- **AI:** OpenAI GPT-4o-mini (cheap, fast, good enough)
- **Payments:** Stripe (subscriptions + one-time)
- **Hosting:** Vercel
- **Auth:** Clerk (or NextAuth)

## Pricing

- **Free:** 3 emails/month
- **Pro:** $29/mo — unlimited emails
- **Team:** $79/mo — 5 seats
